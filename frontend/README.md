# MenuScan frontend

This directory is the runnable Next.js application. It contains the diner menu, merchant admin, server actions, Supabase clients, and frontend utility scripts.

```bash
npm install
cp .env.local.example .env.local
npm run dev
```

Open `http://localhost:3000/m/sofra`. Database schema, seed data, migrations, and SQL tests live in `../backend`.

From the repository root, the same server can be started with `npm run dev`.
